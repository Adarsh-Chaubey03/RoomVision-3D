# RoomVision 3D

**Design. Visualize. Experience.**

An interactive 2D/3D room planner for creating floor plans, arranging furniture, and visualizing interior spaces in real time.

[Live Demo](https://roomvision.adarshchaubey.tech/) · [Source Code](https://github.com/Adarsh-Chaubey03/RoomVision-3D)

## Features

- **2D floor planning** — Create rooms and walls, add doors and windows, and measure layouts.
- **3D visualization** — Explore your design with an interactive camera, materials, lighting, and shadows.
- **Furniture catalog** — Add, move, rotate, resize, and customize furniture and decor.
- **Editing tools** — Use snapping, object selection, undo, and redo.
- **Project management** — Autosave designs in the browser and manage named projects.
- **Import and export** — Save and load designs using JSON files.

## Run Locally

**Requirements:** Node.js 22 LTS and Git.

```bash
git clone https://github.com/Adarsh-Chaubey03/RoomVision-3D.git
cd RoomVision-3D
npm install
npm run dev
```

Open the local URL shown by Vite, usually `http://localhost:5173`.

## Commands
